# F1: Vision data

Notebook: `notebooks/Feba_F1_vision_data.ipynb` (Colab, run top to bottom). Seed 42.

## VERITE

- Source: Hugging Face `stefpapad/VERITE` (gated), revision `858e30e`; 664 images.
- 1,001 caption records: 338 true, 338 miscaptioned, 325 out-of-context. All image paths resolve.
- Split by image (GroupShuffleSplit, 70 / 15 / 15), so an image never appears in two splits:

| Split | Records | Images |
|---|---:|---:|
| Train | 704 | 463 |
| Validation | 151 | 100 |
| Test | 146 | 100 |

- RED-DOT evidence (commit `4dd44fd`): 1,352 files, 1,104 non-empty, 248 empty, 0 invalid. Relevance was not checked.

## GenImage

- Source: Hugging Face `nebula/GenImage-arrow`, revision `3f4b9f9`, configs `biggan-train` (real and BigGAN) and `sd14-train` (Stable Diffusion v1.4). Licence CC BY-NC-SA 4.0.
- Train and validation use real + BigGAN. Stable Diffusion v1.4 is held out for the test set.

| Split | Real | AI-generated | Total |
|---|---:|---|---:|
| Train | 4,000 | 5,000 BigGAN | 9,000 |
| Validation | 1,000 | 1,000 BigGAN | 2,000 |
| Test | 1,000 | 1,000 Stable Diffusion v1.4 | 2,000 |
| Total | 6,000 | 7,000 | 13,000 |

- 13,000 unique MD5 hashes, so no image is in two splits.
- Every image is saved twice on Drive: the original file (`raw_export_path`) and a 256×256 RGB JPEG copy at quality 95 (`normalized_export_path`). The copy keeps the aspect ratio and fills the rest with grey (127, 127, 127). Images smaller than 256 px are not enlarged.

## Original format and size

| Split | Class | Format | Size (px) |
|---|---|---|---|
| Train, validation | BigGAN | PNG | 128×128 |
| Test | Stable Diffusion v1.4 | PNG | 512×512 |
| All | Real | JPEG | 51 to 4,272 per side, 97% not square |

AI images are fixed-size PNGs and real photos are JPEGs of varying size. A detector trained on the original files can learn this difference instead of signs of generation (see F6).

## Files

- `data/processed/vision/genimage_{train,validation,test}_manifest.csv`: one row per image with source, original format and size, and both file paths.
- `data/processed/vision/verite_manifest.csv`: VERITE records with split and file paths.
- `data/processed/vision/verite.jsonl`: VERITE in the shared record format (`python -m src.vision.load_verite --input data/processed/vision/verite_manifest.csv`).
- `data/processed/vision/red_dot_evidence_report.json`.
- `results/F1/f1_verification_results.json`, `results/F1/final_dataset_distribution.csv`.

## Limitations

- MD5 finds exact duplicates only.
- One held-out generator (Stable Diffusion v1.4).
- Train has more AI images (5,000) than real images (4,000).
- In the 256×256 copies, every BigGAN image sits inside a grey border (128 px image on a 256 px canvas), while Stable Diffusion images fill the canvas and most real photos get bars on two sides.
- Images are not in git. They are on Drive under `MyDrive/TwinCheck/data/processed/vision/`.

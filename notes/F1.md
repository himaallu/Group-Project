**Project:** TwinCheck
**Owner:** Feba

## 1. VERITE

- Records: 1,001 (true 338, miscaptioned 338, out-of-context 325)
- Unique images: 663, all valid, none missing
- One unreferenced image (`false_179.jpeg`) is not used

Split by image ID (seed 42), so the same image never appears in two splits:

| Split | Records | Images |
| :---- | ----: | ----: |
| Train | 701 | 464 |
| Validation | 149 | 99 |
| Test | 151 | 100 |
| Total | 1,001 | 663 |

No image overlap between splits.

**RED-DOT evidence:** 1,352 evidence files inspected; 1,104 non-empty, 248 empty, 0 invalid. Relevance and correctness of the evidence were not checked.

## 2. GenImage

Source: Hugging Face `nebula/GenImage-arrow` (licence CC-BY-NC-SA-4.0).

Images exported to the shared Drive (`data/processed/vision/genimage/`): 6,000 real, 6,000 BigGAN and 6,000 Stable Diffusion v1.4.

The detector is trained and validated on real and BigGAN images. Stable Diffusion v1.4 is never seen in training or validation and is the unseen-generator test set.

| Split | Real | AI-generated | Total |
| :---- | ----: | :---- | ----: |
| Train | 4,000 | 5,000 BigGAN | 9,000 |
| Validation | 1,000 | 1,000 BigGAN | 2,000 |
| Test (unseen generator) | 1,000 | 1,000 Stable Diffusion v1.4 | 2,000 |
| Total | 6,000 | 7,000 | 13,000 |

- The 1,000 real test images are sampled with seed 42 from the exported real training images.
- The Stable Diffusion test images are the 1,000 exported in the `validation` folder.
- `source_split` and `exported_path` in each manifest give the Drive folder of every image.

**Leakage checks (MD5):**

| Check | Result |
| :---- | ----: |
| Duplicate images within each split | 0 |
| Train–validation overlap | 0 |
| Train–test overlap | 0 |
| Validation–test overlap | 0 |
| Test AI generator used in train/validation | No |

The Midjourney test partition was also inspected (11,998 unique images after removing 2 duplicates, `midjourney_test_duplicate_report.csv`). It is not part of the experiment splits.

Run from the repo root:

```
python src/vision/genimage_splits.py
```

## 4. Limitations

- MD5 checks find exact duplicates only, not resized or recompressed copies.
- The unseen-generator test covers one generator (Stable Diffusion v1.4).
- Train has more AI images (5,000) than real images (4,000).

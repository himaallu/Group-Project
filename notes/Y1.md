# Y1 notes (Youssef)
- X-FACT Arabic is 2,090 claims, all from misbar.com; labels come already coarse-mapped by X-FACT, so the original Arabic verdict is not available. After our map: 838 contradicted, 55 supported, 26 unverified; 1,171 dropped (1,118 partly true/misleading, 53 other).
- About 25% of X-FACT Arabic evidence links are fact-check sites (mostly misbar.com itself, which often states the verdict). Dropping them leaves 3,400 of 4,463 snippets on kept claims; only 3 kept claims lose all snippets.
- M4FC has 614 Arabic claims (CLAUDE.md said ~860), 613 false and 1 true, and no evidence text. We use all 614 as test (nobody trains on M4FC) plus 156 true captions as supported (M4FC balanced setting), 770 records in total.
- M4FC main file has empty evidence; `m4fc_ar_test_ctx.jsonl` adds M4FC context items (from the fact-check article) as one English snippet, so it is near-gold evidence and must be reported as such.
- Supported Arabic claims are rare in both datasets, so Y2 depends on translated English pairs for the entail class, and macro-F1 on X-FACT AR test (123/9/4) will have wide confidence intervals.

# R4 · NLI (Rathi) — summary

1. v1: 32,658 weak pairs with labels copied from the claim label (+ `_B` swaps, random-snippet neutrals, Youssef's 2,658 Arabic pairs). Weak-val macro-F1 rose 0.40 → 0.76 but gold macro-F1 fell (EN 0.37 → 0.12, AR 0.44 → 0.16; XLM-R the same): the gold pairs are a claim's own snippets, 75% neutral, so v1 learned "on-topic snippet → copy the claim's label", the shortcut the project audits.
2. v2: kept only pairs the zero-shot model agrees with (p ≥ 0.5) and added own-snippet hard neutrals → 18,525 pairs (3,226 `_B` contradictions, 2,977 hard neutrals). Gold macro-F1 EN 0.334, AR 0.473 vs zero-shot 0.371 / 0.443: the collapse is gone but there is no clear gain (mean 0.403 vs 0.407).
3. The gold set is small (EN has only 10 entail and 8 contradict pairs), so differences of a few points are within noise; zero-shot stays the default in `src/nli/score.py`.
4. `features/nli_v2/` has v2 scores for every split and twin file, so the verdict head can be trained on them as a "fine-tuned NLI" ablation (v2 saw `_B` swaps, which may help ESR).
5. Bug found and fixed: the XLM-R v2 run resumed a leftover v1 checkpoint and trained 0 steps; checkpoints now carry a run key and are deleted when a run finishes. XLM-R v2 not rerun (time).

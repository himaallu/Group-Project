# F10: Vision strengthening (Feba)

- Leakage now uses all 218 VERITE photos (5-fold CV). Decoupled changes 13.3% of verdicts [9.2–18.3] and fused 18.3% [13.3–23.4], McNemar p = 0.007, so decoupling reduces leakage but doesn't remove it.
- With seeds 42/43/44, ViT-B/16 beats ResNet-50 on the unseen Stable Diffusion test every time: AUROC 0.761 ± 0.010 vs 0.598 ± 0.018, with a gap of +0.14 to +0.18 (p < 0.001 per seed).
- The weak ResNet-50 was a BatchNorm bug: the frozen layers kept updating their statistics. With them frozen, validation accuracy goes from 0.843 to 0.983 and test AUROC from 0.610 to 0.714 (one seed).
- Static INT8 still distorts ResNet-50 scores (AUROC 0.626 → 0.460 on F5, 0.702 → 0.666 with the fix), so ResNet-50 stays FP32 in ONNX.
- Limits: the BatchNorm fix has one seed, the test set still has one unseen generator, and the input is still 96 px. Details are in `results/F10/README.md`.

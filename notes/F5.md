# F5: Vision experiments (status: code ready, GPU run pending)

- **Detectors:** `src/vision/train_detector.py` trains ResNet-50 and ViT-B/16 from ImageNet weights, with only the last 4 blocks and the head trainable. Settings: 3 epochs, AdamW lr 1e-4, cosine schedule, augmentation (random resized crop, flip, JPEG 60–95, blur), seed 42, on the same seen / unseen-BigGAN / unseen-SD settings as the F3 CLIP probe.
- **Evaluation:** `src/vision/evaluate_detectors.py` evaluates every detector and the CLIP probe clean and under JPEG 50, JPEG 70 and a 20% crop → `results/F5/cnn_vit.csv`.
- **Explanations and deployment:** `src/vision/gradcam.py` makes Grad-CAM for 8 validation images (3 real, 3 SD, 2 BigGAN). `src/vision/export_onnx.py` does the ONNX export (opset 17), checks it against PyTorch, and times ms per image.
- **How to run:** use `notebooks/F5_vision_experiments_colab.ipynb` on a T4. Checkpoints and ONNX files go to Drive `MyDrive/twincheck/models/F5/` (ViT is over 300 MB, so it stays out of git). The notebook pushes only the result files.
- **Checked on CPU with 4 images per generator:** training, evaluation, Grad-CAM and ONNX export all run, and ONNX Runtime matches PyTorch (max abs diff ≤ 1.6e-6). No results yet.

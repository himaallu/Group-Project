# F5: Grad-CAM, robustness, ONNX, CNN vs ViT

- **Setup:** ResNet-50 and ViT-B/16 detectors (last 4 blocks + head, 3 epochs, crop/flip/JPEG/blur augmentation, seed 42) on the F1 GenImage split: train and validation real + BigGAN, test real + Stable Diffusion v1.4 (unseen generator). Run on Colab (L4) with `notebooks/F5_vision_experiments_colab.ipynb`.
- **Validation (accuracy / AUROC):** ResNet-50 0.991 / 1.000; ViT-B/16 0.997 / 1.000. Validation accuracy is already 0.985 / 0.996 after the first epoch.
- **Unseen test (accuracy / AUROC / recall):** ResNet-50 0.505 / 0.713 / 0.012; ViT-B/16 0.538 / 0.885 / 0.080. Both models call almost every Stable Diffusion image real.
- **Robustness:** JPEG 50, JPEG 70 and 20% crop change accuracy by less than 0.01 on both splits (`results/F5/cnn_vit.csv`).
- **Grad-CAM:** 8 images per model (`reports/figures/fig_gradcam_*.png`); BigGAN images get P(AI) ≥ 0.98, all 3 Stable Diffusion images get P(AI) ≤ 0.06.
- **ONNX:** ResNet-50 15.51 ms, ViT-B/16 85.73 ms per image on CPU; outputs match PyTorch (max difference 2.4e-06).
- **Limitations:** one seed and one unseen generator; no W&B logging; the CLIP probe comparison is in F3.

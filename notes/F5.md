# F5: Vision experiments (status: done)

- **Detectors:** ResNet-50 and ViT-B/16 (`src/vision/train_detector.py`), last 4 blocks + head trainable, 3 epochs, with crop, flip, JPEG 60–95 and blur augmentation. Seen, unseen-BigGAN and unseen-SD settings with seed 42; seen repeated with seeds 43 and 44. Run on Colab (L4), logged to W&B.
- **Results** (`results/F5/cnn_vit.csv`, clean accuracy / AUROC): seen ResNet-50 0.974 / 0.996, ViT-B/16 0.984 / 0.998 (mean of 3 seeds), CLIP probe 0.988 / 0.999; unseen BigGAN 0.725 / 0.890, 0.785 / 0.902, 0.860 / 0.981; unseen SD 0.501 / 0.708, 0.534 / 0.881, 0.507 / 0.870.
- **Robustness:** the same table has JPEG 50, JPEG 70 and 20% crop for every model and setting. CLIP probe seen accuracy under JPEG 50 is 0.820; ResNet-50 0.978, ViT-B/16 0.985.
- **Grad-CAM and ONNX:** `reports/figures/fig_gradcam_resnet50.png` (8 images) with P(AI) per image in `results/F5/gradcam_*.csv`; the ViT-B/16 figure needs a rerun of `src.vision.gradcam` after the target-layer fix; ONNX ResNet-50 27.96 ms and ViT-B/16 92.63 ms per image on CPU (`results/F5/onnx_latency.csv`).
- **Not done:** no Midjourney test (images not available), so the unseen settings hold out BigGAN or SD instead; unseen settings use seed 42 only.

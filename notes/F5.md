# F5: CNN vs ViT, robustness, Grad-CAM, ONNX

Notebook: `notebooks/F5_vision_experiments_colab.ipynb` (Colab T4, run after F3).

## Input

Every GenImage image gets the F3 preprocessing before training or testing: pixels only, centre crop, 96 px, JPEG with the settings of a real training photo, and the same greyscale images as F3. File format and image size therefore tell the models nothing. The 13,000 prepared images are cached on Drive (`MyDrive/TwinCheck/data/processed/vision/genimage_debiased96_jpeg.pkl`).

## Detectors

ResNet-50 and ViT-B/16 (ImageNet weights, last 4 blocks + head trained), 3 epochs, AdamW (lr 1e-4, weight decay 0.05), cosine schedule, batch 64, fp16, seed 42. Augmentation: random resized crop (0.6–1), flip, JPEG 60–95, blur (p 0.3). Train and validation are real + BigGAN; test is real + Stable Diffusion v1.4, never seen in training. Threshold 0.5.

| Model | BigGAN val. accuracy | BigGAN val. AUROC | SD v1.4 test accuracy | SD v1.4 test AUROC | SD v1.4 recall |
|---|---:|---:|---:|---:|---:|
| ResNet-50 | 0.842 | 0.982 | 0.504 | 0.610 | 0.013 |
| ViT-B/16 | 0.992 | 1.000 | 0.555 | 0.754 | 0.126 |
| CLIP probe (F3) | 0.958 | 0.992 | 0.542 | 0.620 | 0.156 |

- ViT-B/16 is the best on both splits. ResNet-50 finds only 68.7% of BigGAN images.
- On Stable Diffusion all three call most images real; ViT-B/16 ranks them best (AUROC 0.754).

## Robustness

JPEG 50, JPEG 70 and a 20% centre crop change test accuracy by at most 0.017 and lower test AUROC by at most 0.043 (CLIP probe, JPEG 70). Full table in `results/F5/README.md`.

## Grad-CAM

8 images per model (`reports/figures/fig_gradcam_*.png`). Real photos get P(AI) ≤ 0.002. The 3 Stable Diffusion images get ≤ 0.010 (ResNet-50) and ≤ 0.198 (ViT-B/16), so all are missed. The 2 BigGAN images get 0.959 and 0.070 (ResNet-50), 1.000 and 0.995 (ViT-B/16).

## ONNX and INT8

Colab T4 runtime, CPU with 2 threads, batch 1.

| Model | Size | CPU ms | Same decision as PyTorch (500 test images) | Test AUROC (500) |
|---|---:|---:|---:|---:|
| ResNet-50 FP32 | 94.0 MB | 96.2 | 100% | 0.626 |
| ResNet-50 INT8 | 23.7 MB | 141.4 | 99.0% | 0.826 |
| ViT-B/16 FP32 | 343.6 MB | 481.7 | 100% | 0.771 |
| ViT-B/16 INT8 | 87.3 MB | 432.7 | 98.2% | 0.770 |

- INT8 makes both files about 4 times smaller.
- ViT-B/16 INT8 keeps its scores (AUROC 0.770 vs 0.771) and is 10% faster.
- ResNet-50 INT8 is slower and its scores move a lot (AUROC 0.626 to 0.826), so it is not a faithful copy of the FP32 model.
- GPU (PyTorch, T4): 8.0 ms ResNet-50, 15.1 ms ViT-B/16.

## Limitations

- One seed (42) and one unseen generator.
- 96 px input gives the models less detail.
- The INT8 check uses 500 of the 2,000 test images.

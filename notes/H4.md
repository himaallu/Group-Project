# H4 notes (Himasri, Tue 17 Nov) — λ grid + calibration settings

- **Chosen settings:** λ_inv = 1, λ_sens = 0.5 (val twin score 0.950, val macro-F1 0.357 vs 0.367 at λ = 0, within the 1-point rule); Adam lr 1e-3, 64 groups per batch, early stopping on val macro-F1 (patience 5), zero-shot mDeBERTa NLI features, R2/R3 relevance; calibration T = 0.892, τ = 0 for the pipeline (`models/verdict_calib.json`, twin s42).
- **Grid pattern:** λ_sens drives ESR and the unrelated rate (val 0.46 → 0.91 and 0.22 → 1.00 at λ_sens = 0.5); λ_sens = 1 costs 2–4 F1 points; λ_inv alone does not raise paraphrase consistency (0.905 → 0.84–0.87), so the invariance term helps only together with λ_sens.
- **Test, notwin → twin:** ESR 52.2 → 89.7 and unrelated 42.4 → 100 (p < 0.001 all seeds), paraphrase consistency unchanged (~91, partly because R3's `_P` are near-copies), macro-F1 −1.1 points. Unrelated = 100% is easy for this head: `_C` evidence has reranker relevance < 0.1, so `share_relevant` = 0 flags it directly (reading relevance, which is the right reason).
- **Honest caveat for the report:** much of the ESR gain is a shift toward "contradicted" (supported sources predicted contradicted 40% → 61%); evidence-driven flips are 18.4% → 30.5%. Fine-tuned NLI (R4) should make the swap visible in the NLI features instead of the bias.
- **Calibration:** T < 1 (class weighting makes the head under-confident); the Unverified threshold stays 0 because the head already over-predicts unverified and a threshold can only add more; next try: lighter class weights.

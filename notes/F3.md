# F3: Authenticity probe, image leakage test, baselines, MAAI901 skeleton

- **Probe:** CLIP ViT-L/14 embeddings with logistic regression and linear SVM, trained and validated on real + BigGAN, tested on real + Stable Diffusion v1.4 (unseen generator). Test AUROC 0.860 (LR) and 0.903 (SVM), but recall at the validation threshold is only 0.024 and 0.014, so transfer to the unseen generator is weak (`results/F3/F3_FINAL_SUMMARY.csv`).
- **Leakage (VERITE):** 323 photos with true and miscaptioned captions and a VAE twin. Decoupled (similarity only) and fused (similarity + authenticity score + product) models give the same pair verdicts: test 60.8% on originals and twins, ALR 7.8% (4/51); validation ALR 12.2%. Fusion shows no gain in accuracy or ALR.
- **Baselines on English originals:** claim-only (TF-IDF + logistic regression) and similarity (12 lexical features + LightGBM, 3 seeds) on MultiFC and AVeriTeC test (`results/F3/baselines_originals.csv`).
- **Skeleton:** `reports/maai901_report/main.tex` has 12 sections.
- **Limitations:** small VERITE test set (51 pairs); the 323 twins include 12 that F2 later removed for faces; one unseen generator only. The notebook does not log to W&B; baseline runs are offline and need `wandb sync`.

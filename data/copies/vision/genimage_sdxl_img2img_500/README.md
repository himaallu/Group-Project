# SDXL img2img edits of 500 GenImage test images (Feba, F2)

- 500 JPEGs, one per row of `data/copies/vision/sdxl_generation_manifest.csv` (file name = `edit_id`). SDXL img2img, strength 0.25, 20 steps, guidance 5.0.

# H5 · Ablations, AVeriTeC, calibration, bootstrap (Himasri) — zero-shot NLI run

1. **What ran:** `notebooks/H5_experiments_colab.ipynb` (Colab): `python -m src.eval.run_h5` = 4 variants × seeds 42/43/44 trained on MultiFC train + R3 train twins (`twin` = H4 λ_inv 1 / λ_sens 0.5, `notwin`, `twin_norel` = no reranker, `twin_noent` = no entity match), each applied to MultiFC test + twins and AVeriTeC test (`avt_*`, `src/verdict/predict.py`); calibration fitted on MultiFC val (`*_cal`); paired bootstrap 1,000 resamples (`bootstrap.json`); tables via `src/eval/report.py` → `reports/tables/`.
2. **Settings:** zero-shot mDeBERTa NLI features (`features/nli_zeroshot/`, + `averitec_test.parquet`); otherwise as H4. `twin` / `notwin` reproduce the H4 numbers exactly. Models in `models/H5/`. No W&B (team decision).
3. **Ablations, MultiFC test (mean over seeds, full twin model → ablation):** no reranker: macro-F1 35.2 → 30.1, ESR 89.7 → 68.7, unrelated 100 → 81.0, para. cons. 91.4 → 87.4 (F1/ESR/unrelated p < 0.001 every seed); no entity match: macro-F1 35.2 → 33.8, ESR 89.7 → 86.8 (significant in seed 42 only); no twin loss: see H4 (ESR −38, unrelated −58 points).
4. **AVeriTeC test (429 claims):** macro-F1 twin 38.3 ± 2.0 vs notwin 38.0 ± 2.9 (n.s. in all seeds): the twin loss does not hurt a second dataset. Calibration fitted on MultiFC transfers: ECE notwin 9.8 → 5.0, twin 11.0 → 9.0.
5. **Files:** `summary.csv` (mean ± sd), `bootstrap.json`, `preds_*` / `val_logits_*` / `metrics_*`; tables `reports/tables/{main_results,twin_results}.tex`, `metrics_by_model.csv`. Rerun with R4: `python -m src.eval.run_h5 --nli-dir features/nli_v1 --tag _r4`.

# R3 · English twins (Rathi)

- **What ran:** `notebooks/R3_twins_colab.ipynb` on Colab: `src/copies/make_twins.py` picks the sources (supported, ≥ 2 snippets with relevance > 0.3, seed 42) and builds `_P` (Qwen3-8B 4-bit paraphrase + entity/number check, up to 3 tries), `_B` (one place / person / year swapped in every snippet that mentions it) and `_C` (evidence of a donor claim with no shared entity and reranker relevance < 0.1); `src/copies/checks.py` checks every twin automatically.
- **Settings:** 500 test sources (MultiFC test) + 3,000 train sources (MultiFC train), seed 42; replacement names come from train-split entities only (seen ≥ 5 times); years move 2–5 years and never past 2025; reranker `RathiAbeth/twincheck-reranker-v1`. No model was trained, so there is no W&B run.
- **Key numbers:** test 955 twins (174 `_P`, 281 `_B`, 500 `_C`), train 5,705 twins (986 `_P`, 1,719 `_B`, 3,000 `_C`). Swaps: 904 place, 898 person, 198 year. Paraphrases kept: 35% (the rest changed or dropped a name, date or number). `_B` impossible for 44% of sources (no claim entity in the snippets). Checks: 0 failures in test; 1 in train (`multifc_030465_C`: donor relevance is logged as 0.1 because it was rounded to 4 decimals; the generator only accepts scores below 0.1).
- **Files (in git):** `data/copies/en/{test,train}.jsonl`, `sources.csv`, `twin_log.csv` (what each twin changed); `features/relevance_copies_en.parquet`, `features/entities_copies_en.jsonl` (twin snippets scored, for H3); `make_twins_report.json`, `checks.json`, `samples/{P,B,C}_10.jsonl`.
- **Run again:** `python -m src.copies.make_twins` then `python -m src.copies.checks` (GPU needed for `_P`; `--skip-paraphrase` runs on CPU). Tests: `python -m pytest tests/copies -q`.

# H4 · Twin loss λ grid + calibration (Himasri)

1. **What ran:** `notebooks/H4_grid_calibration_colab.ipynb` (Colab T4): zero-shot NLI on R3 twins → `features/nli_zeroshot/copies_en/`; `src/verdict/grid.py` (12 λ runs, seed 42, then `twin` = chosen λ and `notwin` = λ 0 with seeds 42/43/44); `src/verdict/calibrate.py` per seed (val logits → test); `src/eval/compare.py` paired bootstrap (1,000 resamples by base id). Earlier prep in this folder: `handcheck_*.csv`, `zeroshot_gold_check.json`.
2. **Settings:** grid λ_inv ∈ {0, 0.5, 1, 2} × λ_sens ∈ {0, 0.5, 1}; choice = best mean of val paraphrase consistency / ESR / unrelated rate on held-out twins of 10% of train sources, with val macro-F1 ≥ λ0 − 1 point → **λ_inv = 1, λ_sens = 0.5** (`selected_lambda.json`, `grid_summary.csv`). Calibration: T 0.80–0.89 (twin), τ = 0 in 5 of 6 fits (`models/verdict_calib_*.json`; pipeline uses `models/verdict_calib.json` = twin s42). No W&B (team decision).
3. **Key numbers, test (mean ± sd, 3 seeds), notwin → twin:** ESR 52.2 ± 3.0 → **89.7 ± 0.9**; unrelated rate 42.4 ± 24.4 → **100.0 ± 0.0**; paraphrase consistency 91.2 → 91.4 (n.s.); macro-F1 36.3 ± 0.5 → 35.2 ± 0.7; ECE 5.4 → 8.2, after calibration 7.0. Bootstrap (`bootstrap_twin_vs_notwin.json`): ESR +35 to +42 and unrelated +32 to +81 points, p < 0.001 in every seed; macro-F1 −0.1 to −2.3 (significant only s42).
4. **Caveat:** the twin model also calls 61% of the supported *source* claims contradicted (notwin 40%), so much of the ESR gain is a shift toward "contradicted"; swaps that flip the verdict to contradicted rise 18.4% → 30.5% (`esr_vs_source_bias.json`).
5. **Files:** `preds_{twin,notwin}[_cal]_s*.jsonl`, `val_logits_*`, `metrics_*`, `test_metrics_by_seed.csv`, `grid/`; models in `models/verdict_{twin,notwin}_s*/`; twin NLI features in `features/nli_zeroshot/copies_en/`.

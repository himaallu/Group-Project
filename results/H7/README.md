# H7 · Model selection evidence (Himasri)

1. **What ran:** `python -m src.eval.model_selection` (verdict-head classifiers on the same 10 features, MultiFC train → test + twins) and `python -m src.eval.nli_selection` (zero-shot NLI checkpoints on the 300 gold pairs, CPU timing after a warm-up); bootstrap of our twin-loss MLP vs each alternative with `src/eval/compare.py` (seed 42, 1,000 resamples).
2. **Settings:** same features / splits / test sets as H5 (zero-shot NLI, reranker relevance, entity match); LR class-balanced; LightGBM class-balanced, 300 trees, lr 0.05 (deterministic: identical over seeds 42/43/44); "aug" = train twins added as labelled examples (the non-differentiable stand-in for the twin loss); MLP rows from `results/H5/summary.csv`. NLI: premise = snippet, hypothesis = claim, macro-F1 with bootstrap 95% CI. No W&B (team decision).
3. **Verdict head (`verdict_head_selection.csv`):** LightGBM has the best macro-F1 without twins (38.4) but flips on a third of paraphrases (consistency 66.7) and almost never says unverified on unrelated evidence (7.4). With twins, the MLP + twin loss beats twins-as-data on ESR (89.7 vs 80.4 LightGBM / 79.7 LR, +8.5 / +9.3 points, p < 0.001) and on paraphrase consistency vs LightGBM (+13.2, p < 0.001), for 1.4–2.6 F1 points (`bootstrap_head_selection.json`). Only a differentiable model can use the KL "keep the answer" term.
4. **NLI (`nli_selection.csv`):** mDeBERTa-base EN 0.367 / AR 0.443, 279M params, 90 ms/pair; XLM-R-large 0.382 / 0.502, 560M, 178 ms; DeBERTa-v3-large (English only) 0.427, 435M, 218 ms; fine-tuned v1 0.124 / 0.168, v2 0.334 / 0.473. All zero-shot CIs overlap: mDeBERTa is the one multilingual model that is smallest and fastest; XLM-R-large is the natural upgrade for Arabic (+6 points, not significant on 150 pairs).
5. **Files:** `results/H7/{verdict_head_selection.csv, nli_selection.csv, bootstrap_head_selection.json, preds_*}`; scripts `src/eval/{model_selection,nli_selection}.py`. Other choices already measured elsewhere: retrieval hybrid vs BM25 / dense (`results/R5/`), reranker fine-tuning (`results/R2/`), extractor Qwen vs rule (`results/Y3/`), CLIP probe (`results/F3/`), baselines (`results/F4/audit_E0.csv`).

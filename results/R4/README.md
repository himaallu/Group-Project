# R4 · NLI fine-tuning (Rathi)

- **What ran:** `src/nli/build_pairs.py` → `src/nli/train.py` on mDeBERTa-v3-base XNLI (`MoritzLaurer/mDeBERTa-v3-base-xnli-multilingual-nli-2mil7`), evaluated on 300 gold pairs (150 EN, 150 AR). **v1:** 32,658 weak pairs, labels copied from the claim label (+ XLM-R-large comparison). **v2:** 18,525 pairs (17,880 EN + 645 AR): a weak pair is kept only if the zero-shot model agrees (top class, p ≥ 0.5), plus own-snippet "hard neutrals"; 3,226 `_B` swap pairs kept as contradict.
- **Settings:** lr 2e-5 (XLM-R 1e-5), batch 16, max len 256, 2 epochs, warmup 10%, fp32/TF32, seed 42, NVIDIA L4 (v1 19 min, v2 10.5 min, XLM-R v1 33 min).
- **W&B:** v2 https://forge.coreweave.com/wandb/rathiabeth-uowd/twincheck/runs/hmtd5olh · v1 https://forge.coreweave.com/wandb/rathiabeth-uowd/twincheck/runs/gepd51e6 · XLM-R v1 https://forge.coreweave.com/wandb/rathiabeth-uowd/twincheck/runs/e50h261l
- **Key numbers (gold macro-F1, EN / AR):** zero-shot 0.371 / 0.443; v1 0.124 / 0.162 (label shortcut); **v2 0.334 / 0.473** (mean 0.403 vs zero-shot 0.407: a tie, EN −3.8, AR +3.1 points); XLM-R zero-shot 0.382 / 0.502, v1 0.124 / 0.174. Zero-shot stays the default NLI model in `src/nli/score.py`. The XLM-R v2 run resumed a stale v1 checkpoint (0 training steps), so it was discarded; `train.py` now ties checkpoints to their run.
- **Files:** `results/R4/{gold_eval,pairs_report}.json` (v2), `results/R4/v1_*.json`, `data/nli/{train,val_weak}.jsonl` (v2) and `data/nli/v1/`, `features/nli_v2/` and `features/nli_v1/` (scores for every split + twins); weights on the HF Hub `RathiAbeth/twincheck-nli-v2` and `-v1`.
